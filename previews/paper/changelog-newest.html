Keyline Icons v1.4.1: Every icon under the name shadcn/ui imports

Released · 30 Sept 2026

No drawing changes since 1.4.0. The set still holds 1233.

React

Every icon now also imports under its name plus Icon, so CheckIcon works beside Check, in React and React Native. That is the name shadcn/ui's own components import, so a project made in shadcn/create switches to Keyline with one find-and-replace on the import path. Its spinner is the one exception: Loader2Icon is LoaderCircleIcon here.
