Renamed in 2.6.0

2.6.0 renamed seven drawings and its changelog did not say so. align-left is text-align-start, align-center is text-align-center, align-right is text-align-end, align-justify is text-align-justify, align-left-2 is text-align-2-start and align-right-2 is text-align-2-end, and flower is circles-five. The old names still import in React and React Native, marked deprecated, and still resolve in the CLI and the MCP server, until the next major. Change them before then.
